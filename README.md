# «Зомби в доме» — онлайн-прототип

## Текущее состояние
- Настраиваемое поле генерируется вместе с предметами и препятствиями.
- Поддерживается несколько игроков: сначала сервер ждёт подключения, после чего начинается матч.
- Игровые предметы включают «зомби», «аптечку» и «оружие», которые влияют на состояние персонажа.
- Реализован туман войны, здоровье и инвентарь персонажа.
- Управление игроком происходит через сервер; доступен бот для тестирования.

## Как запустить
1. Установите зависимости из `requirements.txt`.
2. Запустите сервер командой `python main.py`.
3. Подключайте клиентов (например, через `client/`) для участия в игре.
