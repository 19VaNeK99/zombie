# «Зомби в доме» — онлайн-прототип

## Текущее состояние
- Генерируется поле произвольного размера с препятствиями, стартом и финишем.
- Несколько игроков подключаются к серверу и играют пошагово: в начале хода бросается "кубик" на количество действий.
- Функционирует туман войны: при перемещении открываются новые клетки, доступные всем участникам.
- На карте появляются зомби, аптечки, оружие, а также ключ и канистра с топливом.
- Для побега нужно добыть ключ и топливо хотя бы одному игроку, после чего дверь остаётся открытой для всех.
- Реализованы инвентарь, здоровье персонажей, опасные зоны с шансом нанести урон, перемещение зомби при выживании игрока.
- Поддерживаются события старта, завершения и перезапуска матча, синхронизация состояний и уведомления о ходе игры.

## Как запустить
1. Установите зависимости из `requirements.txt` (например, `pip install -r requirements.txt`).
2. Запустите сервер командой `uvicorn main:app --reload` (по умолчанию порт `8000`).
3. Подключайте клиентов по вебсокету `ws://<host>:8000/ws` (в репозитории есть пример в `client/`).
